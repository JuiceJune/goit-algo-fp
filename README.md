# Завдання 7. Метод Монте-Карло — висновки

## Опис

Симуляція кидання двох кубиків `NUM_ROLLS = 1_000_000` разів (`task_7.py`). Для кожного кидка обчислювалась сума чисел на кубиках, підраховувалась частота появи кожної суми (2–12), і на основі частот обчислювалась імовірність кожної суми методом Монте-Карло. Результат порівняно з аналітичними ймовірностями (класична теорія ймовірностей для двох кубиків).

## Висновки

- Максимальне відхилення результатів Монте-Карло від аналітичних розрахунків склало **0.03 процентних пункти** — практично точний збіг.
- Форма розподілу підтверджена: імовірність зростає від суми 2 до суми 7 (найімовірніша сума при киданні двох кубиків) і симетрично спадає до суми 12 — це відповідає теоретичному трикутному розподілу.
- Точність методу Монте-Карло напряму залежить від кількості випробувань (закон великих чисел): чим більше кидків, тим ближче емпірична ймовірність до теоретичної. При меншій кількості кидків (наприклад, 1000) відхилення значно більші — це можна перевірити, зменшивши `NUM_ROLLS` у коді.
- Метод Монте-Карло підтвердив коректність аналітичної таблиці ймовірностей та продемонстрував, що для оцінки ймовірностей складних (або аналітично важких) випадкових процесів достатньо великої кількості симуляцій замість точних формул.
